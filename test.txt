How to deploy web application to the server?
    1. Install git
    2. Create a folder and open in vs code
    3. create index.html file
    4. create github respository
    5. open terminal and write the commands

    - when we add the new repository
            - git init
                initilise the local respository
            - git add .
                    (.) means all files 
            - git commit -m "commit message"
                - saves the changes in the local respository
            - git branch -m main 
                - creates the local main branch
            - git remote add origin https://github.com/Ravindrarathod58/test_app.git
                - adds the cloud repository created on github
            
            - git config --global user.email "email_id"
            - git config --global user.name "githubName"

            - git push -u origin main   
                    - push the local changes to cloud repository


        when the repository is already added then use following commands to push the changes

                    1. git add .
                    2. git commit -m "message"
                    3. git push

        if we want to deploy or make our webpage availbale to everyone over the internet
        then we require the server to host our website / html files

        we are not going to create the server by ourself
        we will use the cloud services to deploy the application

        - netlify
        - vercel
        - render
        - github
        - firebase
        - aws
        - GCP
        - azure

        1. static application   
                - without backend only HTML files
        2. dynamic application  
                - backend languages like java, python, nodejs

        we are going to use the netlify for the static hosting
         - open netlify account
                - login with github


        if you make any changes in the code then again we dont have to visit the netlify
        just push the changes to github it automatically updates on the netlify 
        this called CICD
